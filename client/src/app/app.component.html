Setup

Here's how to find it:

  1. Open the HorizonXI Launcher.
  2. Go to the Extensions tab.
  3. Click Open Folder next to Addons.
  4. Copy the folder path from the window that opens and paste it below.

Note: that button opens the Addons folder, not the game folder itself — if the path you paste ends in "addons" (e.g. F:\HorizonXI\Game\addons), we'll automatically strip that off so it still points to the right place.

Now let's grab your profile info:

  1. Open https://horizonxi.com/players/{{ username }} in your browser.
  2. Open Developer Tools (press F12, or right-click the page and choose Inspect) and switch to the Network tab.
  3. Refresh the page.
  4. Find the request named {{ username }} in the list — its URL looks like https://api.horizonxi.com/api/v1/chars/{{ username }}.
  5. Click it, open the Response tab, and copy everything shown there.
  6. Paste it into the box below.

Stay on this page with Developer Tools open — you'll need one more response for the Inventory step next.

Using the same page and Network tab from the last step:

  1. Find the request named inventory in the list — its URL looks like https://api.horizonxi.com/api/v1/chars/{{ setupUsername.trim() }}/inventory.
  2. Click it, open the Response tab, and copy everything shown there.
  3. Paste it into the box below.
